# Public portfolio snapshot

This repository was curated from a fresh clone of `Bmerrysmith/Autonomous-tractor-system` at public commit `ed93be5` on 2026-09-12.

## Included

- the current installable `agrinav` package;
- experiment configurations without machine-specific data paths;
- the full current test suite;
- data ontology, schema, registry, and a public split manifest;
- CI and packaging configuration;
- selected design records and dataset/evaluation documentation;
- a concise case study and machine-readable results summary.

## Excluded

- Git history from the research repository;
- datasets, images, labels, model weights, checkpoints, and run artifacts;
- executed notebooks and private Drive locations;
- archived, superseded, or unsafe inference prototypes;
- agent configuration, MCP configuration, session handoffs, research-paper drafts, and course-management documents;
- unreviewed third-party media or anything whose redistribution rights are unclear.

## Claim policy

Only measured engineering results are presented as outcomes. Overfit metrics are labeled as correctness gates, historical contaminated runs are excluded, and no field-readiness or actuation claim is made.

No open-source license has been added automatically. The repository is public for portfolio review, but reuse rights are not granted unless the owner later selects a license.
