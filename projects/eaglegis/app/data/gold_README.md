# Gold layer deliverables

Generated by `python -m app.pipeline.run`. Do not hand-edit.

`site_manifest.json` is the index: hashes, row counts, and which file the
GitHub Pages site loads (`primary: arcgis`).

| File | Grain | Audience |
|------|-------|----------|
| **`arcgis_agenda_map_data.csv`** | Agenda item + geocoded site | **Website, map, ArcGIS** — canonical public dataset |
| `meetings_public.csv` / `.json` | Meeting (legacy) | Silver-derived summary; cleaned from ArcGIS locations |
| `meetings_ai_public.csv` / `.jsonl` | Agenda item + ML metadata | RAG / training pipelines |
| `meeting_actions_public.csv` | Structured action clause | Additive action feed |
| `site_manifest.json` | — | Frontend cache keys and artifact registry |

## Build order

```
normalized_csv_*/arcgis_agenda_map_data.csv
        → arcgis_agenda_map_data.csv   (merge council + PZDB, LandUseCategory)
        → meetings_ai_public.*         (enriched for ML)
        → meetings_public.*            (meeting-level; locations cleaned from ArcGIS)
```

## Source of truth for locations

Item-level addresses and lat/lon come from the normalized ArcGIS CSVs
(`normalized_csv_council/`, `normalized_csv_pilot/`). Gold ArcGIS copies them
without project-level fallbacks.
